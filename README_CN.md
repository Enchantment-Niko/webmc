# DMCA 政策与版权投诉

如果您是版权所有者（或授权代表），认为本仓库中的内容侵犯了您的版权，请根据《数字千年版权法》（DMCA）向仓库所有者发送正式的侵权通知。

### 1. 投诉提交通道
请通过 GitHub 平台提供的机制（如 Issues、Pull Requests 或直接发送邮件至作者邮箱）提交 DMCA 投诉。**请务必提供以下信息：**
*   您的姓名、地址、电话号码和电子邮件地址。
*   对受版权保护作品的描述（例如：Minecraft 游戏代码、特定素材）。
*   对涉嫌侵权内容的准确描述，并提供 URL 或具体位置，以便我们定位。
*   一份声明，表明您有充分理由相信该使用未经版权所有者、其代理人或法律授权。
*   一份声明，表明通知中的信息是准确的，并且您有权代表版权所有者行事（如有伪证，愿受法律制裁）。
