Q&A

Q: 存档会丢失吗？

A: 存档一般来讲不清除浏览器缓存 / Cookies不会丢失，但请注意定期备份您的存档文件。

Q: 为什么有些版本不支持移动设备？

A: 因为原作者制作时没有为触屏适配，且适配困难

Q: 会收集个人信息吗？

A: 不会。本网站是静态网站，不会收集或窃取您的个人信息。
注：来历不明的客户端可能含有后门代码，请谨慎游玩。

Q: 如何提交更多高版本客户端？

A: 您可以通过访问我们的 GitHub 仓库并创建一个 讨论(Discussions) 来贡献更多高版本的客户端。

访问 Github 仓库

Q: 离线下载什么时候开放？

A: 离线 HTML 大小大，且维护 / 更新困难，只提供英文版原版下载

Q: 目前和 MCJS 的关系是什么？

A: MCJS 是 Enchantment-Niko 的合作伙伴，提供了镜像站点，解决了国内用户访问 Github Pages 慢的问题。

Q: 如何联机 / 联机卡顿？

A: 国外 Relay 联机节点可能访问慢，可以进入游戏添加 wss://relay.mcjs.link/ 为主要节点。
但请注意：联机服务完全公益，请勿滥用（由 MCJS 运营）

关于

关于 Eaglercraft

Eaglercraft 是一个可以在浏览器直接运行的 Minecraft 网页移植项目，使用 TeaVM 和 JavaScript 技术。本页面提供多版本网页启动入口，支持多个游戏版本，支持中文。

项目仅用于学习，请勿用于商业用途。
